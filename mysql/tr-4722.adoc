= TR-4722: NetApp ONTAP上の MySQL データベースのベストプラクティス
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs:

アヌープ・バーティ、マノハル・クルカルニ、ジェフリー・シュタイナーNetApp

[role="lead"]
MySQL とその派生製品 (MariaDB、Percona など) は、多くのエンタープライズ アプリケーションで広く使用されています。これらのアプリケーションは、グローバルなソーシャル ネットワーキング サイトや大規模な電子商取引システムから、数千のデータベース インスタンスを含む SMB ホスティング システムまで多岐にわたります。このドキュメントでは、 NetApp ONTAPデータ管理ソフトウェアに MySQL を導入するための構成要件について説明し、チューニングとストレージ構成に関するガイダンスを提供します。このレポートで指定されている環境、構成、バージョンがご使用の環境をサポートしているかどうかを確認するには、相互運用性マトリックス ツール (IMT) を参照してください。
